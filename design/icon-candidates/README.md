# アイコン案（Nano Banana Pro生成・2026-08-17）

ニュージーランド国旗（紺＋サザンクロスの赤い星）と国土の形、および
okina共有のスタンプ風デザインを参考に5案作成。

| 案 | 内容 | 16pxでの読みやすさ |
| --- | --- | --- |
| A1 | 紺の角丸に白い国土＋赤い星4つ | △（国土が細り、線に見える） |
| A2 | 円形スタンプ（紺のリング＋白地に国土） | ×（小さいと青い輪だけになる） |
| A3 | 紺地に大きめの赤い星4つ＋国土の細い輪郭 | ○（星は残るが国土は消える） |
| A4 | 赤地＋金のリング＋白円に紺の国土 ← **暫定採用** | ◎（赤地が目印になり判別しやすい） |
| A5 | 紺地に金のスタンプ枠＋国土＋星 | △（要素が多く小さいと潰れる） |

⚠️ favicon は 16px で「他のタブと区別できるか」が最優先。
   模様の細かさより地色のコントラストが効くため、暫定で A4 を採用している。
   別案に変える場合は `option-aN.png` を `app/icon.png` / `app/apple-icon.png` /
   `app/favicon.ico` に書き出し直す（**ico は RGBA で保存すること**。
   RGBだと Next のビルドが `The PNG is not in RGBA format!` で落ちる）。
